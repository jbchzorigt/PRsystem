# UI/UX-ийг бодит хэрэглэгчээр турших локал орчин

Энэ хэрэгсэл PRsystem-ийн **жинхэнэ HTML/CSS/JavaScript, API болон PostgreSQL**-ийг
ажиллуулна. Өгөгдөл нь хийсвэр; SMS, email, төлбөрийн бодит үйлчилгээ холбохгүй.
Хүнээр хийсэн туршилтын үр дүн хараахан бүртгэгдээгүй.

## 1. Асаах — macOS / Windows / Linux

Python 3.12+ болон ажиллаж байгаа Docker Desktop/Docker шаардлагатай.
Доорх командыг төслийн үндсэн хавтаснаас ажиллуулна. Эхний удаа Python package,
PostgreSQL 17 image татахад интернет хэрэгтэй.

```bash
python -m pip install -e ".[api,test]" tzdata
python -m scripts.ui_review
```

Terminal дээр дараах мэдээлэл гарна:

- Нээх хаяг: `http://127.0.0.1:8000/reception`
- Тухайн туршилтын буудлын код
- Ресепшн: `reception@ui-review.example.test`
- Менежер: `manager@ui-review.example.test`
- Цэвэрлэгч: `cleaner@ui-review.example.test`
- Зөвхөн энэ удаагийн өгөгдөлд үйлчлэх санамсаргүй түр нууц үг

Нэвтрэх дэлгэцэд terminal-д гарсан буудлын код, сонгосон ажилтны email,
түр нууц үгийг оруулна. Хүмүүс нэг компьютерт ээлжлэн туршиж болно.
Роль солихдоо **Гарах** товч дарж, дараагийн ажилтнаар нэвтэрнэ.
Тусдаа browser profile ашиглавал гурван роль зэрэг нээлттэй байж болно.

8000 порт ашиглагдаж байвал:

```bash
python -m scripts.ui_review --port 8001
```

Өгөгдөл бэлтгэх ба үндсэн уншилтыг шалгаад шууд хаах команд:

```bash
python -m scripts.ui_review --check
```

Туршилт дуусахад terminal-д `Ctrl+C` дарна. Зөвхөн энэ хэрэгслийн үүсгэсэн
бааз, database role, PostgreSQL container устна. Дахин асаахад шинэ буудлын код,
шинэ нууц үг, шинэ өгөгдөлтэй эхэлнэ. Өөрчлөлтүүдийг дараагийн туршилтад хадгалахгүй.

## 3. Хэрэглэгчид өгөх даалгавар

Ажиглагч эхлээд зорилгыг хэлнэ. Аль товч дарахыг зааж өгөхөөс өмнө хэрэглэгч
өөрөө дараагийн алхмаа олж чадаж байгаа эсэхийг тэмдэглэнэ. Зөвхөн хийсвэр
зочин, утас, баримтын мэдээлэл ашиглана.

### Ресепшн

1. 101 өрөөнд 1 хоног байрлах зочин бүртгэ. Хоосон шаардлагатай талбараа
   нэг удаа илгээж, гарсан тайлбараар засаж чадаж байгаа эсэхээ шалга.
2. Баримтын төрөл "Монгол регистр"-ийг сонгож `АБ90010211` оруулна; зочны зөвшөөрлийг
   тэмдэглээд **ХУР-аас татах** дарна. Овог, нэр, төрсөн огноо "ХУР-аар баталгаажсан"
   гэж засах боломжгүй харагдана. `АБ85020311` олдохгүй, `ЖЖ80010100` ХУР ажиллахгүй
   үеийг загварчилна — тэр үед л **Гараар бүртгэх** боломжтой. Бүгд хийсвэр тестийн өгөгдөл.
3. Хийсвэр бэлэн барьцаа 60,000₮ бүртгэ. Байрлалтаа нээгээд барьцааг өрөөний
   төлбөрт суутгаж, үлдсэн 20,000₮-ийг хийсвэр бэлэн төлбөрөөр бүртгэ.
4. Зочны гарах ажиллагааг дуусга. Нэг байрлалт, нэг төлбөр, нэг checkout
   үүссэн эсэх болон дараа хийх ажлаа ойлгож байгаа эсэхийг ажигла.

### Цэвэрлэгч

1. Өөрт оноосон 201 өрөөг дугаар, давхар, ангиллаар нь ол. Ажлыг эхлүүл.
2. Үлдсэн хэмжээнээс их тоо оруулж батлахыг оролд; тайлбарыг уншаад зөв тоо
   `1` болгож гүйцэтгэлийг батал. Дууссан ажил жагсаалтаас арилсан эсэхийг шалга.
3. Ресепшн 101 өрөөг хаасны дараа мэдээллээ шинэчил. Хариуцагчгүй 101 өрөөний
   цэвэрлэгээг өөртөө авч, эхлүүлж, дуусга.
4. Зочны хувийн мэдээлэл, санхүүгийн дүн шаардахгүйгээр ажлаа хийж чадаж
   байгаа эсэхийг ажигла. Checkout-ийн 30 минутын бэлтгэлийн хугацаа хэвээр
   мөрдөгдөх тул цэвэрлэсэн даруйд өрөө дахин худалдаалагдана гэж үзэхгүй.

### Менежер

1. Шинэ ангилал үүсгээд, тэр ангиллаар 202 өрөө бүртгэ. Шинэ ангиллыг
   нэмэлт refresh шаардахгүй сонгож чадаж байгаа эсэхийг шалга.
2. Нэг маягтад бичиж эхлээд, нөгөө маягтыг хадгал. Эхний маягтын бичсэн зүйл
   хэвээр байгаа эсэх, мэдээллээ шинэчлэхэд анхааруулга ойлгомжтой эсэхийг шалга.
3. Онлайн хэсэгт буудлын тайлбарыг шинэ зураг сонголгүй өөрчил. Өмнөх зураг
   үлдэж, техникийн хувилбарын дугаар оруулах шаардлагагүй байгаа эсэхийг шалга.

Мобайл хэмжээг browser-ийн responsive горимоор 320px болгон давтаж болно.
Хүмүүсийн өөрийн утасны бодит хэрэглээг үнэлэх бол тусдаа зөвшөөрсөн test
deployment хэрэгтэй; энэ хэрэгсэл зөвхөн тухайн компьютерийн localhost дээр ажиллана.

## 5. Ажиллахгүй бол

- **Docker эхлээгүй:** Docker Desktop/Docker-ийг асааж дахин ажиллуул.
- **Module олдохгүй:** эхний `pip install` командыг яг хэрэглэж буй Python-оор
  ажиллуулсан эсэх, төслийн үндсэн хавтаст байгаа эсэхийг шалга.
- **Порт эзлэгдсэн:** `--port 8001` ашигла.
- **Test database эсвэл PG host environment үлдсэн:** шинэ terminal нээгээд
  production/test DB-ийн тохиргоо дамжуулахгүйгээр ажиллуул. Launcher өөрийн
  PostgreSQL container-ийг бэлтгэнэ; одоо байгаа буудлын өгөгдлийг seed/reset хийхгүй.
- **Terminal хүчээр хаасан:** зөвхөн үлдсэн review container-уудаа
  `docker ps --filter label=prsystem.purpose=disposable-ui-review` гэж харна.
  Өөрийн зогсоосон сессийн нэрийг баталгаажуулсны дараа `docker rm --force НЭР`
  командаар тэр container-ийг арилгана.

Runtime API нь owner/superuser/BYPASSRLS эрхгүй тусдаа role ашиглана. Localhost
host/origin шалгалттай. Production factory болон deployment тохиргоо өөрчлөгдөөгүй.
